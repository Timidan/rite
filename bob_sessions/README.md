# Bob Sessions

Add genuine IBM Bob task-summary screenshots here before submission.

## What to capture

For each participant, save a screenshot showing the **task summary** from your
IBM Bob session — the panel that shows tasks completed, token/coin consumption,
and session activity for this project.

**Do not fabricate screenshots, task counts, token usage, time savings, or
traction numbers.** The hackathon guide requires genuine evidence.

## File naming

```
bob_sessions/<your-name>-session-<date>.png
```

Example: `bob_sessions/timidan-session-2026-09-26.png`

## What counts as genuine evidence

- The Bob IDE task-summary panel showing real session activity on this project.
- Multiple screenshots across sessions are fine; label them by date.
- Redact any personal information not relevant to the task summary.

## Event allowance note

The recorded event allowance is 40 Bobcoins per participant. Focus screenshots
on proof of use, not on coin balance specifically.
